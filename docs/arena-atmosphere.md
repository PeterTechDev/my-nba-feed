# Arena atmosphere

The homepage uses [arena-neutral.webp](../public/images/arena-neutral.webp) as decorative, generic basketball-arena atmosphere. It is a generated photorealistic illustration, not documentary imagery of a particular team's venue, game or event. Team identity comes from the official crest and semantic text; a runtime team-primary tint is masked above the court.

The asset was edited with the built-in `image_gen` tool, then compressed to WebP with the installed `sharp` library. The shipping file is 1672 × 941 pixels. Its [provenance sidecar](../public/images/arena-neutral.webp.json) preserves the exact edit prompt and source. At the user's request, this replacement removes the original green court paint, green reflections and green lighting. The floor uses natural maple, charcoal and white so it works with every team's lighting, while preserving the original camera composition.
